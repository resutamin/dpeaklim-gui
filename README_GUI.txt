==========================================================================
 Disable Peak Limiter GUI  (dpeaklim GUI 版)
 ― Windows オーディオエンジンのピークリミッタを無効化する GUI ―
==========================================================================

元ツール : dpeaklim Ver 1.2  (c) 2013-2019 Suguru Kawamoto / MIT License
GUI 化・信頼性改善 : 本フォルダ dpeaklim-gui


■ これは何か
--------------------------------------------------------------------------
Windows の共有オーディオエンジン(audiodg.exe 内 audioeng.dll)には、
再生音が -0.13dB(内部値 0.985)を超えると音量を自動で絞る「ピークリミッタ」
が常時かかっています。本ツールはその閾値をメモリ上だけ書き換えて無効化し、
本来の音をそのまま出力させます。再起動すると元に戻ります(仕様)。


■ 「たまに動かなくなる」の原因と、本GUIでの対策
--------------------------------------------------------------------------
原因: 物理メモリを書き換える方式のため、書き換える瞬間に audioeng.dll が
      物理メモリに「常駐」している必要がある。ところが今の Windows(especially
      Win11)は、音を鳴らしていないと audiodg が audioeng.dll を読み込まない/
      すぐ解放する。元ツールは「サービス再起動→即スキャン」なので、無音の
      タイミングだと対象が見つからず失敗する。= これが "たまに動かない" の正体。
      (Win10 1909 の頃は audiodg の常駐挙動が緩く成功しやすかった)

本GUIの対策:
  (1) 管理者権限で自動起動          … 権限不足による無言の失敗を防止
  (2) 無音ストリームを再生して常駐化 … 書き換え前に audioeng.dll を強制的に常駐
  (3) 常駐が安定するまで待機してから書き換え
  (4) 失敗したら自動リトライ(待機時間を延ばして最大3回)
  (5) 成功/失敗をはっきり表示        … 効いたのか分からない問題を解消
  (6) ワンクリックで復元
  ※ 物理メモリ書き換えの中核ロジックは作者オリジナルのまま(安定性維持)。


■ 使い方
--------------------------------------------------------------------------
1. bin\dpeaklim_gui.exe をダブルクリック (UAC で「はい」)
2. 「状態(事前診断)」が全部 ✓ になっているか確認
     - メモリ整合性(コア分離)が「オン」の場合は書き換えがブロックされます。
       設定 > プライバシーとセキュリティ > デバイス セキュリティ >
       コア分離 > メモリ整合性 を一旦オフ→再起動 が必要です。
3. しきい値を選ぶ(通常は「完全に無効化(推奨)」のまま)
4. 「リミッターを無効化」を押す → ログに ✓完了 が出れば成功
5. 元に戻したいときは「元に戻す(復元)」、または Windows を再起動


■ 注意
--------------------------------------------------------------------------
- 再生/録音アプリは閉じてから実行してください(音が一瞬途切れます)。
- Windows 再起動で設定は元に戻ります。起動時の自動実行は、キャッシュ破損で
  Windows を壊す恐れがあるため意図的に用意していません(元 readme の警告に準拠)。
- Secure Boot 環境では付属ドライバ(inpoutx64.sys)の読み込みが拒否される場合が
  あります。その時はログに「ドライバを開けません」と出ます。
- 自己責任でご使用ください(元ツールの免責に準じます)。


■ ビルド方法
--------------------------------------------------------------------------
[A] すぐビルド(コマンドライン)
      build.bat をダブルクリック → bin\dpeaklim_gui.exe が出来ます
[B] IDE で開く
      dpeaklim_gui.sln を Visual Studio で開く → 構成 Release / x64 でビルド
      (出力先 bin\、VC++ランタイム不要の単体exe)
[C] インストーラーを作る
      build_setup.bat をダブルクリック → bin\dpeaklim_setup.exe が出来ます
      (本体exeとドライバを埋め込んだ単体インストーラー。実行すると
       Program Files へ導入し、ショートカット作成・アンインストーラー同梱・
       「プログラムの追加と削除」に登録。/uninstall で削除)


■ 構成ファイル
--------------------------------------------------------------------------
  dpeaklim_gui.sln / .vcxproj   … Visual Studio プロジェクト
  build.bat                     … コマンドラインビルド
  src\gui.cpp                   … GUI本体 + 信頼性レイヤー(新規)
  src\core.h                    … 中核関数の宣言(新規)
  src\app.manifest              … 視覚スタイル/DPI(新規, 昇格はビルド側で付与)
  src\dpeaklim.cpp              … 作者オリジナル(文字コードのみUTF-8化, CLI main を無効化)
  src\InpOut32.cpp / .h         … 作者オリジナル
  src\stdafx.* / targetver.h    … 作者オリジナル
  bin\inpoutx64.dll / .sys      … InpOut32 ドライバ(実行に必要)
